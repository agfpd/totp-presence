# soft-prompt — инструкции для агента + MCP-инструменты

Связка из двух слоёв: текстовые инструкции в промпте говорят агенту
**когда** проверять идентичность собеседника, MCP-инструменты из
[mcp-server](../mcp-server/) дают **чем** проверять. Агент сам
решает когда нужна верификация и сам вызывает инструменты.

## Когда это подходит

- Как замена или дополнение к `claude-code-hook` — агент проактивно проверяет
  сессию в ситуациях, которые хук не покрывает (read-only
  инструменты, последовательности безобидных действий).
- Для агентов в «мягком» режиме — без жёсткой блокировки, но с
  осознанной проверкой идентичности.

## Установка

1. Установи ядро: `sudo ./core/setup.sh install`
2. Установи интеграцию для файлов сессии:
   `sudo ./examples/claude-code-hook/install.sh` (или создай свою)
3. Подключи MCP-сервер — см. [mcp-server/README.ru.md](../mcp-server/README.ru.md)
4. Открой [prompt.md](./prompt.md), замени `<integration>` на имя
   интеграции (например `claude-code`)
5. Скопируй блок в system prompt или CLAUDE.md агента

## Что агент будет делать

С этим промптом + MCP-инструментами агент:

- Перед чувствительными действиями вызывает `totp_check_session` —
  проверяет, открыта ли сессия.
- Если нет — просит у владельца код и вызывает `totp_verify`.
- Владелец видит зачем агент просит код и решает, давать или нет.
- При сомнении в идентичности — проверяет проактивно.

## Сравнение режимов

| | Только хук | Soft-prompt + MCP | Хук + soft-prompt + MCP |
|---|---|---|---|
| Инъекция не может обойти | да | нет* | да |
| Агент понимает зачем | нет | да | да |
| Агент проверяет проактивно | нет | да | да |
| Работает без поддержки хуков | нет | да | — |

\* Инъекция может заставить агента не вызывать инструменты проверки,
но не может произвести валидный TOTP-код.

**Рекомендация:** комбинируй все три слоя. Хук блокирует на уровне
OS (инъекция не обойдёт). Soft-prompt даёт понимание (агент знает
зачем и когда). MCP даёт инструменты.

## Адаптация

**Другое имя интеграции:** замени `<integration>` в prompt.md на
имя своей интеграции. Имя = префикс файлов в `/etc/totp-presence/`
(например `aider` → `aider-session`, `aider-config`).

**Другие триггеры:** список «когда проверять» в prompt.md —
отправная точка. Адаптируй под свой случай: если агент работает
только с кодом и не имеет доступа к SSH — секция про VPN/GUI
избыточна.
