В разговоре с Артуром и в любых русскоязычных документах писать живым русским языком, не калькой с английского.

**Why:** Артур указал явно (17.04.2026): «У тебя прекрасное чувство русского языка, почему ты им не пользуешься». Дефолт с англицизмами через каждое слово раздражает, читается как машинный перевод. Артур думал, что я так пишу by design — это была инерция от англоязычных тренировочных данных.

**How to apply:**
- В диалоге — носитель с носителем, без академичного формализма, но и без жаргонизмов и англицизмов через каждое слово.
- В документах — академический тон, но идиоматичный русский, не кальки.
- Если очень хочется английский термин — в скобках рядом русский эквивалент: «hook (перехватчик)», а не голое «хук».
- Технические имена не переводить: TOTP, MCP, sudo, root, sudoers, FHS, RFC 6238, base32, имена полей конфигурации в backticks (`matcher`, `EXTRA_SAFE_TOOLS`).
- hook оставлять как есть — устоявшийся термин Claude Code, переводы вроде «перехватчик» звучат странно.
- Стандартные замены: mitigation → защитная мера, lazy → по требованию, ephemeral → временный, deadlock → взаимная блокировка, headless → без терминала, allowlist → список разрешённых, footgun → грабли, by design → намеренно, security-критичный → критичный для безопасности, brute-force → перебор, snippet → фрагмент, deny → отказ, malformed → повреждённый, regex-метасимволы → метасимволы регулярного выражения, symlink → символическая ссылка.

**Distinction:** в общении со мной (Артуром) — не академично, в духе живого диалога носителей. В русскоязычных документах для публики — академичный тон, но всё равно идиоматичный.
